Pasang Smart Grocery

Gunakan sebagai aplikasi di Komputer (PC/Laptop) & HP

Klik untuk langsung menambahkan ke layar utama atau desktop
🖥️
Komputer / Laptop (Windows, Mac, Linux)
Google Chrome, Microsoft Edge, Brave
1 Perhatikan ujung kanan address bar (kolom URL browser) di atas.
2 Klik ikon Pasang / Install 🖥️ atau tanda panah unduh ⬇️.
3 Atau klik tombol menu titik tiga (⋮) di browser > pilih "Instal Smart Grocery".
💡 Aplikasi akan terbuka di jendela mandiri tanpa browser dan bisa langsung di-pin ke Taskbar!
📱
Ponsel Android (Chrome & Samsung Internet)
PWA Resmi Bebas Google Play Store
1 Buka menu browser: titik tiga (⋮) di Chrome atau garis tiga (☰) di Samsung Internet.
2 Pilih "Tambahkan ke Layar Utama" (Add to Home screen) atau "Instal Aplikasi".
🛡️ Penting: Solusi Jika Muncul "Unsafe app blocked"
Pesan "This app was built for an older version of Android" terjadi jika di HP Anda masih tersimpan file APK / shortcut lama bernama GroceryTracker.

Cara Mengatasinya:
1. Hapus (Uninstall) aplikasi lama bernama GroceryTracker di daftar aplikasi HP.
2. Buka link web resmi ini di browser lalu pilih Add to Home screen.
3. Versi web PWA baru ini 100% aman, resmi, dan selalu otomatis sinkron dengan data cloud.
🍏
iPhone / iPad (Safari)
iOS & iPadOS
1 Tekan tombol Share ⎋ (ikon kotak panah ke atas) di bagian bawah browser Safari.
2 Gulir ke bawah dan pilih "Add to Home Screen" (Tambahkan ke Layar Utama).
